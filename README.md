# Student Record Project

A simple Python mini project that stores student information and automatically calculates the student's grade and pass/fail result.

## Features

- Stores student name and roll number
- Stores and updates student marks
- Automatically calculates grade
- Checks Pass/Fail status
- Displays the complete student record

## Concepts Used

- Python Dictionary
- `if`, `elif`, `else`
- `for` loop
- Dictionary methods
- Conditional statements
- Formatted strings

## Example

The program stores:

- Name
- Roll Number
- Marks
- Grade
- Result

- Python 3
